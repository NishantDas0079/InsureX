## 📖 About InsureX

**InsureX** is an AI-powered insurance platform designed to simplify and modernize how people understand, choose, and manage insurance. By combining intelligent automation with a clean, intuitive interface, InsureX aims to remove the confusion and friction typically associated with traditional insurance processes.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your machine

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/NishantDas0079/InsureX.git
   cd InsureX
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**

   Create a `.env.local` file in the root directory and add any required API keys:
   ```bash
   VITE_API_KEY=your_api_key_here
   ```
   > *Update variable names based on what your app actually uses.*

4. **Run the app locally**
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to the local development URL shown in your terminal (typically `http://localhost:5173` or `http://localhost:3000`).
